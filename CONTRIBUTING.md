# Contribuer

GeoExif est un projet **personnel** de carnet naturaliste. Les contributions sont bienvenues, sans engagement de revue rapide.

## Avant de proposer un changement

1. Décris le besoin terrain (pas seulement la technique)
2. Évite d’alourdir l’interface : le but reste un outil de sortie, pas une usine à gaz
3. Ne commit **aucune** donnée de terrain, clé API, ou chemin machine personnelle

## Pull requests

- Une idée = une PR si possible
- Indique Windows + version Python testés
- Pour l’audio : préciser BirdNET Live / Birda / Chirpity

## Issues

Merci d’indiquer :

- Version GeoExif (`À propos`)
- Windows 10/11
- Message d’erreur complet si plantage
- Étapes pour reproduire

## Code de conduite (simple)

Respect, bienveillance, pas de harcèlement. Les débats naturalistes restent factuels.
